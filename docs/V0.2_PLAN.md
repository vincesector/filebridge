# filebridge v0.2 plan (approved by the owner 2026-10-20)

Goal: easier for the agent (1, 5), safer (2, 3), works in more places (4, 6). Do NOT push to GitHub; commit locally on a branch `v0.2`.

1. **`serve` as an MCP tool.** New tool `browser_upload_own(paths, selector=None, ttl=1800)` that starts the localhost server in the background (not blocking the MCP server), returns `{urls, snippet, expires_in_s, server_id}`; plus `serve_status(server_id)` (served counts, done/expired) and `serve_stop(server_id)`. Snippet stays top-level-await form (not IIFE). CLI `serve` keeps working.

2. **Safe file access by default + approval.**
   - Config file `~/.filebridge/config.toml` (create on first run with defaults): `allowed_roots = ["~/Projects", "~/Movies", "~/Downloads", "~/Documents", "<cwd>"]` (cwd = the working dir of the MCP client process), `blocked_globs` hard denylist that can never be uploaded/served even with approval: `**/.ssh/**`, `**/.gnupg/**`, `**/*.pem`, `**/*.key`, `**/id_rsa*`, `**/.env`, `**/.env.*`, `**/.aws/**`, `**/.config/gcloud/**`, `**/Library/Keychains/**`, `**/.netrc`, `**/.npmrc`, `**/.pypirc`, `**/*secrets*.json`, `**/Cookies`, `**/Login Data`.
   - Every tool that reads local files (set_files, drop_files, upload_own/serve, clipboard_files, local_copy src, transfer when src is local) resolves real paths (follow symlinks) and checks them.
   - Inside allowed roots: proceed. Blocked glob: refuse always with error code `PathBlocked`.
   - Outside allowed roots: ask via **MCP elicitation** (ctx.elicit / server.request_context.session.elicit with a boolean confirm schema): "filebridge wants to <action> <path> (<size>) to <destination>. Allow?" Yes -> proceed for that call only; No -> `PathNotAllowed`. If the client doesn't support elicitation -> refuse with `PathNotAllowed` and a message naming the config key to add. CLI: interactive y/N prompt on a TTY, refuse when not a TTY; `--allow-path <dir>` flag adds a root for that run; env `FILEBRIDGE_UNRESTRICTED=1` disables the allowlist (never the denylist).
   - Document clearly that the client's own permission mode may auto-accept elicitations; the denylist is the hard floor.

3. **Single-use links, error codes, verification.**
   - serve URLs: each file URL works exactly once (second GET -> 410), still token + TTL.
   - Structured errors everywhere: `{ok:false, code, message}` with codes: `PathBlocked`, `PathNotAllowed`, `FileNotFound`, `SelectorNotFound`, `TabNotFound`, `FileTooLarge` (configurable `max_bytes`, default none), `FetchBlocked` (snippet catches fetch TypeError and reports the browser blocked localhost: advise enabling the local-network permission), `Timeout`, `NotSignedIn` (headless page shows a login form/URL), `RemoteNotConfigured`.
   - Optional verification: `verify_text` / `verify_selector` arg on set_files/drop/upload_own: after the action, wait (timeout) until the page shows that text or selector (e.g. the filename, or "upload complete"), return `{verified: true/false}`. For upload_own, the snippet returns quickly; add a second snippet `verify_snippet` the agent can run, or poll via the extension. Keep it simple and documented.

4. **Attach to an already-running browser.** `browser_launch(mode="attach", cdp_url="http://127.0.0.1:9222")` (and CLI `browser attach --cdp-url`): connect to a Chrome/Brave the user started with `--remote-debugging-port=9222` (document how; note Chrome 136+ requires a non-default `--user-data-dir` for remote debugging, so explain the trade-off honestly: attach works with a separate profile the user signed into, or with Chrome's own "remote debugging" toggle if available). Never launch or close the user's browser in attach mode.

5. **Target by element reference.** New tool `browser_snapshot(tab)` returning a compact list of interactive elements (role, name/label, text, and a stable ref like `e12`) from the accessibility tree via CDP (`Accessibility.getFullAXTree` or DOM walk), including file inputs, drop zones (elements with dragover/drop listeners or common upload-zone text), buttons. `set_files`, `drop`, `click`, `type` accept `ref` as an alternative to `selector`/coords. Refs map to backendNodeIds for that snapshot.

6. **Polish.**
   - One-line install: `uvx --from git+https://github.com/vincesector/filebridge filebridge mcp` in README (and make sure `pyproject` entry point works with uvx).
   - `--slim` flag for `filebridge mcp`: expose only upload tools (browser_upload_own, set_files, drop, snapshot, tabs, navigate, launch) to save context.
   - Linux/Windows: browser discovery via PATH + standard install dirs (`google-chrome`, `chromium`, `brave-browser`, `%ProgramFiles%`), clipboard via `xclip`/`wl-copy` (Linux) and PowerShell `Set-Clipboard -Path` (Windows), reveal via `xdg-open`/`explorer /select,`. Best effort, clearly marked "untested" where not tested.
   - Big files: warn in results when a file served to the user's browser is > 1 GB ("the tab holds the whole file in memory").
